# Commerce

A full-stack e-commerce web application built with Django and Python.

## Features

- User authentication
- Create and edit listings
- Auction/bidding functionality
- Categories
- Watchlist
- Comments
- Listing search
- Relational database

## Technologies

- Python
- Django
- JavaScript
- HTML
- CSS
- SQLite

## Running Locally

```bash
python manage.py runserver
